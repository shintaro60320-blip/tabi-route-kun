# 旅ルートくんを本人のスマホに入れる手順（とと が一緒にやる・約 10 分）

持ち物：本人の Android（Galaxy）、本人の Google アカウント（ログイン済み）、アプリの URL。

## 1. 本人の Gemini のキーを作る（本人のアカウントで）
※ アプリの設定画面にも「キーを作るページを開く」のボタンと同じ手順が出ます。
1. Chrome で `https://aistudio.google.com/apikey` を開く（本人の Google アカウントでログイン）。
2. 利用規約が出たら読んで同意（**本人が押す**）。
3. 左の「Get API key」→「API キーを作成」→ 新しいプロジェクトで作成。
4. できたキー（`AIza…`）の「コピー」を押す。**画面を撮ったり、人に送ったりしない。**
   - キーは本人の名義。とと は手順を手伝うだけで、キーを控えない。

## 2. アプリをホーム画面に置く
1. Chrome でアプリの URL（`https://<アカウント>.github.io/tabi-route-kun/`）を開く。
2. 右上「⋮」→「ホーム画面に追加」（または「アプリをインストール」）→「追加」。
3. ホーム画面に「旅ルート」の緑のアイコン（白い「旅」）が出る。

## 3. キーを貼る
1. ホーム画面の「旅ルート」を開く → 右上の歯車 → 「Gemini のキー」の欄を長押し →「貼り付け」。
2. 「キーを確かめる」→「使えます（モデル：…）」と出れば完了。
3. 「文字の大きさ」は本人に見てもらって「大きい」にしてもよい。

## 4. お試し
1. 「もどる」→ 行き先に「大阪城」→「おすすめを出す」→「半日」→「このコースで出す」。
2. ルートが出たら 1 か所目を押す → 「Googleマップ 写真・口コミ」でマップアプリが開く。
3. 「地図」→「Googleマップで案内を始める」→ 区間を選ぶ → 経路が出る。

## 本人に伝えること（3 つだけ）
- 料金と時間は**目安**。行く前にお店の営業を確かめてください。
- 「今日の分を使い切りました」と出たら、**夕方以降**にまた使えます（1 日の回数に上限があります）。
- 設定画面のキーは**人に見せない**でください（見せても金はかからないが、回数を使われる）。

## 困った時
| 画面の文言 | すること |
|---|---|
| インターネットにつながっていません | 電波のある所で「もう一度」 |
| キーが正しくないようです | 設定で貼り直して「キーを確かめる」 |
| 今日の分を使い切りました | 夕方以降にまた |
| うまく作れませんでした | 「もう一度」。続くなら行き先の言い方を変える |
| 見つかりませんでした | 行き先を変える（例：大阪城 → 大阪城公園） |
| 声の入力が使えません | 文字で入れる |
