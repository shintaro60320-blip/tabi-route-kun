分かったこと：
- 田舎は市町村記事の「観光」節が候補の正。近傍 10km は駅・郵便局・古墳ばかりでほぼ役に立たん（ふるいで落ちる）。
- 都市は「〇〇市の観光地」カテゴリ（大阪市 99 件）が効くが、市内全域なので**距離の加点**（≤1km +3・≤3km +2・≤6km +1）が無いと目的地から離れた所へ飛ぶ。
- 観光地カテゴリにはコンサートホール・劇場も入っとる → `isVenue` で全部の源から外す。
- Node から Wikipedia を短時間に叩いたら IP ごと 429 になった（Chrome からのアプリは別扱いやが、1 回の生成で 6〜12 回飛ぶ）。同じ行き先・コースの候補はセッション内で使い回す（作り直しで叩き直さん）。
- 店は名指しせんので「やっとらん店」は構造的に出ん。昼の枠は「終わりが 11:30〜14:00 に入る最初の場所の後」。
